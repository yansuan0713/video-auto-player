# 学习通修复验证（v1.2.6）

已在本地复现：先打开课程页，再加载扩展时，“所有网站”权限不会自动为已打开的顶层页面及 about:blank 子页面注入脚本。现在点击“检测当前标签页”、复制诊断或手动下一节时，会按当前文档补注入缺失脚本。已有部分模块的文档不会重复初始化，而会报告启动状态、缺失模块和错误位置。

Chrome 实际加载扩展的回归测试已覆盖上述恢复、普通及 sandbox 空白 iframe、并发恢复、手动点击无变化、并发点击及章节变化确认。Edge 三层 iframe 自然播放结束后的连播测试通过。尚未登录或测试真实学习通，因此这不是对用户实际课程根因或验收的确认。

## Chrome / Edge 本地加载

1. 将修复分支下载并解压；或解压提供的扩展 ZIP。选择包含 `manifest.json` 的目录。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。现有本地扩展使用“重新加载”；新目录使用“加载已解压的扩展”。测试时只启用一份视频自动播放器。
3. 确认弹窗版本为 **1.2.6**。最低浏览器版本为 106，文档定向注入用于避免点击换页后的其他文档。

## 真实课程简短验收

1. 打开学习通课程页，保留自动连播、2x、跳过非视频设置。点击扩展的“检测当前标签页”：顶层和播放器 frame 应显示 `ready`；旧页面可能显示“已补充注入”。
2. 点击“手动下一节”：章节变化后应显示“已确认页面变化”；无变化显示“未确认”，已有导航显示“正在处理中”。整页离开或超过确认窗口时，结果可能无法确认，不会宣称跳转成功。
3. 刷新课程页，从正常播放开始，等视频自然结束，确认只跳一节且新视频开始播放。不要拖进度条到结尾来代替自然结束。
4. 复制诊断现在会先实时检测，不需要先点击检测按钮；初始化失败会附缺失模块与错误位置，检测失败不会复制旧结果。

本修复继续只操作现有页面控件；未改变播放完成条件、学习进度或平台接口。
